# 3D塔防游戏

一个运行在浏览器里的 3D 塔防游戏：随机生成多入口地图，自由建塔、升级和出售，用不同属性的防御塔叠加附着并触发连锁反应。

- 作者 GitHub：[YeSirQoQF](https://github.com/YeSirQoQF)
- 项目仓库：[tower-defence](https://github.com/YeSirQoQF/tower-defence)

## 开始游戏

- [网页版立即开玩](https://yesirqoqf.github.io/tower-defence)

- 双击项目目录中的 `start.bat`
- 或在项目目录执行 `npm start`
- 浏览器打开 `http://127.0.0.1:8080`

不能直接双击 `index.html` 游玩：游戏使用 ES Module 加载本地 Three.js，`file://` 协议下浏览器会拦截模块加载。

## 基本操作

| 操作                | 功能                                   |
| ------------------- | -------------------------------------- |
| 左键                | 建造防御塔；点击已建好的塔打开升级栏   |
| 右键                | 出售防御塔，返还累计投入的 70%         |
| `1`–`9` / `0` / `-` | 选择防御塔；`0` 是曜辉塔，`-` 是玄蚀塔 |
| 空格 | 提前开始下一波 |
| P / 波次面板暂停键 | 暂停或继续游戏 |
| WASD / 中键拖动     | 平移视角                               |
| Q / E               | 旋转 90°                               |
| 滚轮                | 缩放；可拉近观察格子，也可拉远查看地图 |
| C                   | 回到地图中心                           |
| H                   | 打开 / 关闭游戏说明                    |
| Esc                 | 关闭说明 / 取消选塔                    |

## 游戏模式

| 模式     | 玩法                                                  |
| -------- | ----------------------------------------------------- |
| 常规模式 | 12 波；全部开始并清空后胜利                           |
| 无尽模式 | 波次无限，挑战最高分                                  |
| 巨型模式 | 201×201 超大地图，中央基地，64 个敌方据点由近到远解锁 |

- 第一波前是**无限准备时间**，不会自动开波，也没有提前开波奖励。
- 第一波开始后，每 **30 秒**自动开下一波；波次可以重叠，倒计时与战斗是否结束无关。
- 可以随时提前开波，获得 `剩余秒数 × 1.2` 的提前奖励。
- 巨型模式的据点频率随难度变化：轻松每 2 波解锁 1 个，标准每波 1 个，高压每波 2 个。

### 难度

## 防御塔

| 塔       | 价格 | 定位                                                                     |
| -------- | ---- | ------------------------------------------------------------------------ |
| 脉冲枪塔 | 55   | 高频单体，可升级超频或穿透                                               |
| 震荡炮塔 | 105  | 范围伤害，适合清理集群                                                   |
| 供能塔   | 100  | 治疗、强化周围塔的射程/攻击/生命上限                                     |
| 魔法塔   | 500  | 4.2 格射程，抽取附近属性塔的属性并 3 连发；没有属性塔时打 3 次无属性魔法 |
| 霜冻塔   | 80   | 冰属性，减速                                                             |
| 灼烧塔   | 95   | 火属性，持续燃烧                                                         |
| 沧浪塔   | 125  | 水属性，降低敌人攻速和攻击伤害                                           |
| 电涌塔   | 150  | 雷属性，触电持续伤害                                                     |
| 风爆塔   | 300  | 风属性范围伤害，附加风化                                                 |
| 曜辉塔   | 1000 | 光属性魔法，易伤并锁住其他附着                                           |
| 玄蚀塔   | 1000 | 暗属性魔法，反伤并触发暗系反应                                           |

- 所有塔都有生命值；敌人靠近时会攻击相邻塔，多个敌人可以叠加伤害。
- 塔被摧毁后不会返还金币；供能塔可以治疗范围内的塔。
- 脉冲枪塔最多升到 Lv.16，升级时二选一（超频/穿透）；供能塔最多升到 Lv.9，升级时三选一（增幅/过载/生命回路）。升级费用逐次提高。
- 其余防御塔暂时没有升级分支。

## 属性与附着

攻击属性有：无、火、冰、雷、风、水、光、暗。

- **光、暗只来自魔法伤害**。
- 每次属性命中附着 1 点对应属性；每种最多 4 点，默认半衰期 1 秒。
- 当敌人身上有光附着时，**其他属性不会随时间衰减**；光本身仍会衰减。
- 敌人头顶的彩色小点表示当前附着属性；小点越大，附着越多。

| 属性 | 效果                                                        |
| ---- | ----------------------------------------------------------- |
| 冰   | 霜冻：降低移动速度，层数越高越慢                            |
| 火   | 燃烧：每 0.7 秒造成火层数相关的物理/火伤害                  |
| 雷   | 触电：每 0.7 秒造成雷层数相关的物理/雷伤害                  |
| 风   | 风化：周期性对自身和附近敌人造成物理/风伤害                 |
| 水   | 迟缓：降低敌人攻速，并小幅度降低其攻击伤害                  |
| 光   | 圣裁：每层使敌人受到的最终伤害 +15%，并阻止其他属性自然衰减 |
| 暗   | 幽冥：敌人造成伤害时受到暗层数相关的暗属性魔法反伤          |

## 属性反应

反应有优先级，单个敌人有短暂反应冷却；反应伤害本身不会额外附着属性。

| 反应 | 条件          | 效果                                                               |
| ---- | ------------- | ------------------------------------------------------------------ |
| 湮灭 | 光 + 暗       | 消耗全部光/暗，造成大范围无属性魔法伤害；自身额外损失 20% 最大生命 |
| 燃竭 | 暗 + 火       | 永久火属性魔法持续伤害，威力略高于 4 层燃烧；每名敌人最多一次      |
| 迷醉 | 暗 + 水       | 永久敌我不分，攻击可能转向附近敌人；每名敌人最多一次               |
| 凝滞 | 暗 + 冰       | 永久大幅降低移速和攻速；每名敌人最多一次                           |
| 并联 | 暗 + 雷       | 雷属性魔法范围伤害，波及敌人越多伤害越高                           |
| 席卷 | 暗 + 风       | 将燃竭/迷醉/凝滞扩散给附近敌人                                     |
| 超导 | 雷 + 冰       | 立即结算燃烧、触电、风化与感电，造成物理/无属性爆发                |
| 蒸汽 | 火 + 冰       | 转化为水                                                           |
| 凝结 | 水 + 冰       | 转化为 2 冰                                                        |
| 熄灭 | 火 + 水       | 相互抵消                                                           |
| 感电 | 雷 + 水       | 消耗全部雷/水，持续造成雷属性物理伤害                              |
| 超载 | 雷 + 火       | 消耗全部雷/火，造成范围火属性物理伤害                              |
| 扩散 | 风 + 其他属性 | 将 1 点该属性扩散给附近敌人                                        |

## 实战提示

1. **先铺附着再打反应**：火、雷、风、暗的层数越高，反应爆发越明显。
2. **光适合做“锁附着”核心**：光存在时其他属性不会自然衰减，可以先叠满再触发反应。
3. **暗系反应会永久改变敌人**：被燃竭、迷醉或凝滞的敌人会一直带着效果，优先处理。
4. **魔法塔看附近有没有属性塔**：附近有属性塔时它会抽取属性打 3 连发；没有时仍会打 3 次无属性魔法。
5. **不要把塔紧贴路口**：敌人会攻击相邻塔；留出距离或放置供能塔会更稳。
6. **第一波前可以慢慢布阵**：这是无限准备时间，先确定塔位和供能范围再开始。
