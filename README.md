# 3D塔防游戏

一个运行在浏览器里的 3D 塔防游戏：随机生成多入口地图，自由建塔、升级和出售，用不同属性的防御塔叠加附着并触发连锁反应。

- 作者 GitHub：[YeSirQoQF](https://github.com/YeSirQoQF)
- 项目仓库：[tower-defence](https://github.com/YeSirQoQF/tower-defence)

## 开始游戏

- [网页版立即开玩](https://yesirqoqf.github.io/tower-defence)
- 双击项目目录中的 `start.bat`或在项目目录执行 `npm start`，然后浏览器打开 `http://127.0.0.1:8080`。
- 首次打开会进入首页：选择游戏模式和难度。
  - **开始游戏**：生成新种子。
  - **重新开始**：沿用当前种子。
  - **游戏说明**：在首页直接打开 README 说明。
  - 游戏中按 `Esc` 打开暂停菜单，可继续、换新地图、查看/复制当前种子或返回首页。

不能直接双击 `index.html` 游玩：游戏使用 ES Module 加载本地 Three.js，`file://` 协议下浏览器会拦截模块加载。

游戏内说明会读取同目录的 `README.md` 并渲染成 HTML；把游戏部署到其他网站时，请一并保留 `README.md`，否则帮助面板会显示加载失败提示。

## 基本操作

| 操作                            | 功能                                           |
| ------------------------------- | ---------------------------------------------- |
| 左键                            | 建造防御塔；点击已建塔打开升级栏；点击基地维修 |
| 右键拖动                        | 平移视角                                       |
| 中键                            | 出售防御塔，返还累计投入的 70%                 |
| `1`–`9` / `0` / `-` / `=`       | 选择防御塔；`0` 是曜辉塔，`-` 是玄蚀塔，`=` 是诅咒塔（仅轻松模式） |
| 空格                            | 提前开始下一波                                 |
| `P` / 波次面板暂停键            | 暂停或继续游戏                                 |
| `Esc`                           | 打开暂停菜单；帮助打开时先关闭帮助             |
| WASD                            | 平移视角                                       |
| Q / E                           | 旋转 90°                                       |
| 滚轮                            | 缩放；可拉近观察格子，也可拉远查看地图         |
| C                               | 回到地图中心                                   |
| H                               | 打开 / 关闭游戏说明                            |

游戏页面内已禁用浏览器右键菜单；在防御塔面板、帮助说明等界面右键也不会弹出浏览器菜单。

## 游戏模式

| 模式     | 玩法                                                  |
| -------- | ----------------------------------------------------- |
| 常规模式 | 12 波；全部开始并清空后胜利                           |
| 无尽模式 | 波次无限，挑战最高分                                  |
| 巨型模式 | 201×201 超大地图，中央基地，64 个敌方据点由近到远解锁 |

- 第一波前是**无限准备时间**，不会自动开波，也没有提前开波奖励。
- 第一波开始后，每 **30 秒**自动开下一波；波次可以重叠，倒计时与战斗是否结束无关。
- 可以随时提前开波，获得 `剩余秒数 × 1.2` 的提前奖励。
- 巨型模式的据点频率随难度变化：轻松每 2 波解锁 1 个，标准每波 1 个，高压每波 2 个。
- 后期敌人数量、生命上限和精英占比会持续提高；数量和生命没有硬上限。第50波后，每5波出现首领。

### 难度

| 难度 | 初始金币 | 生命 | 敌人强度 | 首个精英 | 巨型据点频率 |
| --- | --- | --- | --- | --- | --- |
| 轻松 | 270 | 22 | 较低 | 第13波 | 每2波1个 |
| 标准 | 300 | 20 | 基准 | 第10波 | 每波1个 |
| 高压 | 340 | 16 | 较高 | 第7波 | 每波2个 |

### 开局流派

标准与高压开局会在游戏内先选择流派：

- **光（直伤流）**：玄蚀塔本局最多建造 1 座。
- **暗（反应流）**：曜辉塔本局最多建造 1 座。

轻松模式不弹出流派选择，曜辉塔和玄蚀塔都正常开放。

## 基地维修

基地生命未满时，点击基地即可维修：

- 每次恢复 1 点生命，不能超过初始最大生命。
- 随时可用，不需要等到没有敌人。
- 冷却 30 秒**游戏时间**，暂停或倍速会影响冷却速度。
- 金币费用随波次和维修次数递增；战斗中有 1.5 倍价格。
- 每次维修后，后续敌人的生命上限永久提高 1%。

### 升级

- 脉冲枪塔：Lv.32，基础45金；升满级总投入约11256金。低等级升级便宜，高等级逐步昂贵；每次升级显著增加射程，并选择超频或穿透。
- 震荡炮塔：Lv.9，升满级总投入约715金；每次提高伤害、射程和爆炸半径。
- 魔法塔：Lv.10，基础300金；升满级总投入约1591金；每级使射程内敌人受到的属性反应伤害+5%。魔法塔与诅咒塔共享反应易伤层数，每层+5%，每个敌人最多20层（100%反应易伤）。
- 供能塔：Lv.25，基础80金；升满级总投入约5431金；每次升级从范围、攻击、生命/治疗、攻速、暴击中选择。
  - 每个供能塔的暴击分支最多强化3次：0%/0% → 10%/15% → 20%/30% → 30%/45%。
  - 多个供能塔的暴击率叠加，全体暴击率上限100%，暴击伤害上限150%。
  - 其他强化同样叠加，但受各自上限约束。
- 其他塔暂未开放升级。

## 属性与附着

攻击属性有：无、火、冰、雷、风、水、光、暗。

- **光、暗只存在魔法伤害**。
- 每次属性命中附着 1 点对应属性；每种最多 4 点。
- 附着改为**线性衰减**：普通属性每 1.5 秒减少 1 点；光/暗每 2.5 秒减少 1 点。
- 当敌人身上有光或暗附着时，**其他属性不会随时间衰减**；光/暗自身仍会衰减。
- 敌人头顶的彩色小点表示当前附着属性；小点越大，附着越多。

| 属性 | 效果                                                        |
| ---- | ----------------------------------------------------------- |
| 冰   | 霜冻：降低移动速度；并以其一半比例减慢攻击、治疗频率        |
| 火   | 燃烧：每 0.7 秒造成火层数相关的物理/火伤害                  |
| 雷   | 触电：每 0.7 秒造成雷层数相关的物理/雷伤害                  |
| 风   | 风化：周期性对自身和附近敌人造成物理/风伤害                 |
| 水 | 混沌：敌人攻击防御塔时不再造成伤害，而是治疗该塔 |
| 光   | 圣裁：每层使最终伤害 +15%，阻止其他附着衰减；并使各附着元素按自身层数降低对应属性抗性，每层 -10% |
| 暗   | 幽冥：造成伤害时反伤每层30%；其他元素不自然衰减；存在时每个附着属性每层额外降低5%对应抗性 |

## 抗性

敌人同时拥有两类独立抗性：

- 物理/魔法抗性
- 火、冰、雷、风、水、光、暗属性抗性

规则：

- 物理/魔法抗性仍由敌人种类决定，并随波次缓慢提高。
- 属性抗性不再绑定敌人种类，而是按难度和波次生成期望值，再加入低方差正态随机波动；最低为0。
- 第1波属性抗性期望：轻松约10%、标准约12%、高压约16%；之后按难度逐步提高。
- 单项抗性上限：普通敌人70%，精英敌人90%。
- 物理抗性+魔法抗性总和不超过140%。
- 重甲最低拥有5%物理和魔法抗性。
- 萨满类敌人的属性抗性会额外降低。
- 减抗效果可以把属性抗性降到负数；负抗性会提高对应属性伤害。
- 真实伤害无视抗性。

## 属性反应

反应有优先级，单个敌人有短暂反应冷却；反应伤害本身不会额外附着属性。

| 反应 | 条件          | 效果                                                                                            |
| ---- | ------------- | ----------------------------------------------------------------------------------------------- |
| 湮灭 | 光 + 暗       | 消耗全部光/暗；3.6格范围无属性魔法伤害；范围内所有敌人受5%最大生命真伤；存活目标中生命上限最高者额外受15%最大生命无属性魔法伤害；若最高者被真伤击杀，则改选剩余存活目标中的最高者；每次湮灭独立判定 |
| 燃竭 | 暗 + 火       | 永久火属性魔法持续伤害与1.5格范围伤害；每0.7秒额外损失2%当前最大生命（至少1）；每名敌人最多触发一次该反应 |
| 迷醉 | 暗 + 水       | 永久敌我不分，攻击可能转向附近敌人；治疗也有50%概率转为伤害；每名敌人最多触发一次该反应 |
| 凝滞 | 暗 + 冰       | 永久降低移速、攻击、治疗与技能频率（攻击/技能约降至20%）；每名敌人最多触发一次该反应 |
| 并联 | 暗 + 雷       | 2.8格雷属性魔法范围伤害，波及敌人越多伤害越高                                                  |
| 腐化 | 暗 + 风       | 将燃竭/迷醉/凝滞扩散给3格内敌人，生成3次风属性伤害风涡；范围内敌人永久全属性抗性-20%，每名敌人最多触发一次该反应的减抗 |
| 超导 | 雷 + 冰       | 立即结算燃烧、触电、风化与感电，造成物理/无属性爆发                                             |
| 融化 | 火 + 冰       | 生成水，并造成水属性物理伤害                                                                    |
| 凝结 | 水 + 冰       | 生成 2 冰                                                                                       |
| 蒸发 | 火 + 水       | 相互抵消，并造成无属性物理伤害                                                                  |
| 感电 | 雷 + 水       | 消耗全部雷/水，持续造成雷属性物理伤害                                                           |
| 超载 | 雷 + 火       | 消耗全部雷/火，造成范围火属性物理伤害                                                           |
| 扩散 | 风 + 其他属性 | 将1点该属性扩散给附近敌人；被扩散到的敌人对应属性抗性-30%、风抗-20%，持续6秒；不叠加，重复刷新 |

## 实战提示

1. **先铺附着再打反应**：层数越高，反应收益越明显。
2. **光/暗都适合做锁附着核心**：任一存在时其他属性不会自然衰减，可以先叠满再触发反应。
3. **暗系反应会永久改变敌人**：被燃竭、迷醉或凝滞的敌人会一直带着效果。
4. **魔法塔看 2 格内有没有属性塔**：有属性塔时抽取属性；没有时仍会打无属性魔法。
5. **诅咒塔很强但会消耗生命值**：它消耗识别范围内所有塔当前生命的4%，末段伤害按消耗量提高，并附加30%消耗生命的无属性魔法伤害；末段仍保留抽取属性。
6. **标准/高压先选流派**：未选择的曜辉/玄蚀塔最多只能建造1座；轻松模式才开放诅咒塔。
7. **萨满和精英萨满会治疗周围敌人**：优先击杀或控制，不要让它们抬高整波的有效生命。
8. **首领到达基地附近会停下继续施压**：它不会攻击基地，但停在约4格外，把召唤间隔缩短到8秒，并且有30%伤害免疫；尽快集火。
9. **考虑不要把塔紧贴路口**：敌人会攻击相邻塔；留出距离或放供能塔更稳。
10. **第一波前可以慢慢布阵**：这是无限准备时间，先规划塔位和供能范围。
