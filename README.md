# 3D塔防游戏

一个运行在浏览器里的 3D 塔防游戏：随机地图、自由建塔、属性附着与连锁反应。

- 作者 GitHub：[YeSirQoQF](https://github.com/YeSirQoQF)
- 项目仓库：[tower-defence](https://github.com/YeSirQoQF/tower-defence)

## 快速开始

- [网页版立即开玩](https://yesirqoqf.github.io/tower-defence)
- 双击项目目录中的 `start.bat`，或在项目目录执行 `npm start`，然后打开 `http://127.0.0.1:8080`。
- 不能直接双击 `index.html`：游戏使用 ES Module 加载本地 Three.js，必须通过本地服务器打开。

首页可以：

- 选择游戏模式和难度；
- **开始游戏**：生成新种子；
- **重新开始**：沿用当前种子；
- **游戏说明**：打开本说明。

游戏中按 `Esc` 打开暂停菜单，可继续、换新地图、查看/复制当前种子或返回首页。

## 操作

| 操作 | 功能 |
| --- | --- |
| 左键 | 建造、选中防御塔、维修基地 |
| 右键拖动 | 平移视角 |
| 中键 | 出售防御塔；镭射塔有嵌入元素塔时优先拆除元素塔 |
| `1`–`9` / `0` / `-` / `=` / `[` | 选择防御塔；`[` 是诅咒塔，仅轻松模式 |
| 空格 | 提前开始下一波 |
| `P` / 暂停按钮 | 暂停或继续 |
| `Esc` | 暂停菜单；帮助打开时先关闭帮助 |
| WASD | 平移视角 |
| Q / E | 旋转 90° |
| 滚轮 | 缩放 |
| C | 回到地图中心 |
| H | 打开/关闭游戏说明 |

游戏内已禁用浏览器右键菜单。

## 模式与难度

| 模式 | 说明 |
| --- | --- |
| 常规 | 12 波，清空后胜利 |
| 无尽 | 无限波次，挑战最高分 |
| 巨型 | 201×201 地图，64 个据点逐波解锁 |

| 难度 | 初始金币 | 生命 | 特点 |
| --- | --- | --- | --- |
| 轻松 | 270 | 22 | 全塔开放，诅咒塔可用 |
| 标准 | 300 | 20 | 基准难度，诅咒塔不可用 |
| 高压 | 340 | 16 | 敌人更强，诅咒塔不可用 |

- 第一波前可以无限准备。
- 第一波开始后每 30 秒自动开下一波，可以提前开波拿金币。
- 后期敌人数量、生命和精英比例会持续提高。
- 当前关闭开局流派选择，曜辉塔和玄蚀塔均可正常建造。

### 镭射塔

- 初始射程略大于诅咒塔，升级后最高约等于原32级脉冲塔射程。
- 优先锁定首领和精英。
- 射线贯穿路径上的所有敌人，并附着2点属性。
- 选中元素塔后点击镭射塔，或选中镭射塔后点击已有元素塔，都可以把元素塔嵌入镭射塔：
  - 嵌入的元素塔不攻击；
  - 镭射塔获得对应属性和伤害类型：光/暗为魔法伤害，其余属性为物理伤害；
  - 出售时优先拆除元素塔，再出售镭射塔。
- 拿着元素塔点击已经嵌入元素的镭射塔，会直接打开镭射塔升级界面。
- 暴击时施加破甲：降低30%物理抗性、20%魔法抗性；有属性时再降低20%对应属性抗性，持续6秒，不可叠加，重复暴击刷新。
- 暴击率超过100%的部分会转为暴击伤害，最多转化50%。

### 升级与暴击

- 脉冲塔可升到16级，只保留超频分支。
- 镭射塔可升到16级，总投入约3500金币。
- 暴击率和暴击伤害没有上限。
- 暴击对魔法塔无效。
- 供能塔的暴击光环仍然只影响其他直接攻击塔。

## 属性附着

- 每种属性最多附着4点。
- 普通属性每1.5秒衰减1点，光/暗每2.5秒衰减1点。
- 光或暗存在时，其他属性不会自然衰减。

| 属性 | 主要效果 |
| --- | --- |
| 冰 | 减速，同时减慢攻击和治疗频率 |
| 火 | 燃烧持续伤害 |
| 雷 | 触电持续伤害 |
| 风 | 范围风化伤害 |
| 水 | 混沌：敌人攻击塔时改为治疗塔 |
| 光 | 圣裁：提高最终伤害，并降低各属性抗性 |
| 暗 | 幽冥：反伤；每层降低对应属性抗性5% |

常见的属性反应包括湮灭、燃竭、迷醉、凝滞、并联、腐化、超导、融化、凝结、蒸发、感电、超载和扩散。实际效果可以在战斗中直接观察。

- 湮灭触发后，该敌人不会再次触发湮灭，但光、暗会补满，并获得物理/魔法抗性-5%、全属性抗性-10%；之后仍会被其他敌人的湮灭波及。
- 扩散现在可以让不同元素减抗共存，同一元素不叠加。
- 圣裁每层降低对应属性抗性15%。
- 扩散使风抗和被扩散属性抗性各降低40%。

## 敌人

- 萨满会治疗周围敌人，精英萨满治疗范围更大。
- 精英和首领拥有红色渐变血条边框。
- 精英·重甲有概率免疫伤害。
- 首领不会主动靠近基地，会在地图上徘徊，并使用瞬移和召唤精英；瞬移冷却8秒，短时间受伤越多越容易发动；它不会攻击基地，且有30%伤害免疫。

## 小提示

1. 第一波前可以慢慢布阵。
2. 光/暗既能增幅伤害，也能延长其他附着。
3. 精英和首领血条有红色边框，优先处理。
4. 魔法塔和元素塔负责铺属性，物理塔负责稳定直伤。
5. 镭射塔适合放在长直路径，优先处理精英和首领。
6. 诅咒塔只在轻松模式开放。
