# 3D塔防游戏

随机地图、自由建塔、属性附着与连锁反应的 3D 塔防游戏。

- [网页版立即开玩](https://yesirqoqf.github.io/tower-defence)
- 作者：[YeSirQoQF](https://github.com/YeSirQoQF)
- 仓库：[tower-defence](https://github.com/YeSirQoQF/tower-defence)

## 快速开始

1. 在首页选择**模式**和**难度**。
2. 点击**开始游戏**（新种子）或**重新开始**（沿用当前种子）。
3. 左键建塔，`空格`开始第一波，清空波次获得金币。
4. 按 `Esc` 暂停；暂停菜单可查看/复制种子、换地图或返回首页。

首次游玩建议先看**操作**和**防御塔图鉴**，遇到具体反应再查**属性速查**。

游戏内帮助和首页的“游戏说明”都会加载本文件。

## 一局怎么玩

- 第一波前是准备时间，可以慢慢布阵。
- 第 1 波开始后，每 30 秒自动开下一波；提前开波会获得金币。
- 击杀敌人获得金币，漏怪扣基地生命。
- 左键点击已有塔可升级；中键出售，返还累计投入的 70%。
- 属性命中会附加元素；元素叠高后触发反应，造成额外伤害或控制。
- 后期敌人数量和强度持续提高，精英和首领需要优先处理。
- 当前关闭开局流派选择，曜辉塔和玄蚀塔都可正常建造。
- 铸币塔暂时停用，相关代码保留。

### 镭射塔

- 初始射程 6.3 格，满级 9.3 格，优先锁定首领和精英。
- 射线贯穿路径上的所有敌人，并附着 2 点属性。
- 选中元素塔点击镭射塔，或选中镭射塔点击已有元素塔，都可嵌入。
- 嵌入塔不攻击，只改变镭射塔的属性和伤害类型。
- 拿着元素塔点击已经嵌入的镭射塔，会直接打开升级界面。
- 光/暗为魔法伤害，其余属性为物理伤害。
- 魔法塔和诅咒塔会识别镭射塔当前嵌入的属性。
- 暴击时施加破甲：物理抗性 -30%、魔法抗性 -20%、对应属性抗性 -20%，持续 6 秒，不可叠加。
- 暴击率超过 100% 的部分转化为暴击伤害，最多转化 50%。
- 出售时优先拆除嵌入的元素塔，再出售镭射塔。

### 升级与暴击

- 脉冲塔和镭射塔最高 16 级。
- 暴击率和暴击伤害没有上限。
- 暴击只作用于直接攻击，不作用于反应伤害。
- 暴击对魔法塔无效。

## 属性速查

- 每种属性最多附着 4 点。
- 普通属性每 1.5 秒衰减 1 点，光/暗每 2.5 秒衰减 1 点。
- 光或暗存在时，其他属性不会自然衰减。

| 属性 | 效果                                         |
| ---- | -------------------------------------------- |
| 冰   | 霜冻：降低移速，并减慢攻击/治疗频率          |
| 火   | 燃烧：持续伤害                               |
| 雷   | 触电：持续伤害                               |
| 风   | 风化：范围伤害                               |
| 水   | 混沌：敌人攻击防御塔时改为治疗防御塔         |
| 光   | 圣裁：提高最终伤害，每层降低对应属性抗性 15% |
| 暗   | 幽冥：反伤，每层降低对应属性抗性 5%          |

### 常见反应

| 反应 | 组合      | 效果                               |
| ---- | --------- | ---------------------------------- |
| 湮灭 | 光 + 暗   | 范围真伤与魔法爆发                 |
| 燃竭 | 暗 + 火   | 永久火 DoT，并额外损失最大生命     |
| 迷醉 | 暗 + 水   | 敌人可能攻击同伴，治疗可能转为伤害 |
| 凝滞 | 暗 + 冰   | 大幅降低移速、攻击、治疗和技能频率 |
| 并联 | 暗 + 雷   | 范围雷魔法，波及越多伤害越高       |
| 腐化 | 暗 + 风   | 扩散暗系减益，并造成风涡伤害       |
| 超导 | 雷 + 冰   | 结算持续伤害并爆发                 |
| 融化 | 火 + 冰   | 生成水并造成水属性伤害             |
| 凝结 | 水 + 冰   | 生成冰                             |
| 蒸发 | 火 + 水   | 抵消并造成无属性伤害               |
| 感电 | 雷 + 水   | 持续雷属性伤害                     |
| 超载 | 雷 + 火   | 范围火属性伤害                     |
| 扩散 | 风 + 其他 | 扩散属性并降低对应抗性             |

- 湮灭触发后，该敌人不会再次自行触发湮灭，但会补满光/暗并获得额外减抗，仍会被其他敌人的湮灭波及。
- 扩散的不同元素减抗可以共存，同元素不叠加；风抗和被扩散属性抗性各降低 40%。

## 新手建议

1. 第一波前先铺好输出和供能范围。
2. 先集中升级少量塔，再逐步扩展。
3. 光/暗既能增伤也能锁定附着，适合做反应核心。
4. 精英和首领血条有红色边框，优先集火。
5. 镭射塔适合长直路径，优先处理精英和首领。
